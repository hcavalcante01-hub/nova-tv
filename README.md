# Nova TV

Protótipo pessoal e não comercial de uma interface para Android TV, em desenvolvimento.

## Objetivo

Explorar uma tela inicial com navegação por controle remoto, cartões nas cores de cada aplicativo e imagens de filmes e séries ao fundo. O protótipo é testado no computador; não há instalação automática nem alterações na configuração atual da TV.

## Estado do projeto

- Prévia visual local com navegação simulada.
- Cartões para Prime Video, TizenTube, Kick, Twitch, Downloader e UniTV.
- Imagens demonstrativas em transição; não representam catálogos confirmados dos serviços.
- Integração com a API do TMDB planejada, ainda não ativada.
- Este repositório documenta o projeto; o código e o APK ainda não foram publicados aqui.

## Uso planejado do TMDB

Consultar títulos, sinopses, pôsteres e informações de disponibilidade de filmes e séries no Brasil para exibição no protótipo. Os dados de disponibilidade do TMDB não serão apresentados como catálogo oficial completo de um serviço. Não há reprodução, hospedagem ou distribuição de filmes e séries.

A integração incluirá os créditos e as atribuições exigidos pelo TMDB e seus fornecedores de dados. Este projeto é independente e não é afiliado aos serviços exibidos.

## Credenciais

Chaves e tokens devem permanecer somente em arquivos locais, como `segredos.properties`, excluídos do controle de versão. Não publique credenciais, dados pessoais ou arquivos de configuração privados em commits, issues ou capturas.

## Marcas e imagens

Logos e marcas pertencem aos respectivos titulares. Os arquivos de marcas e as imagens demonstrativas da prévia local não estão incluídos neste repositório.
